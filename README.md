# NightFallRanch_Game

# Qué es Nightfall Ranch

Nightfall Ranch es un videojuego shooter donde el jugador tendrá la tarea de defender su rancho
El gameplay se trata de balancear tu atención entre 2 tareas:
    Evitar que los Lobos (que constantemente entrarán a tu Rancho) logren matar a tus ovejas
    Mantener tus Generadores funcionando al cargarlos para evitar que su bateria llegue a 0 y tu Cerca Electrica falle, haciendo que toda la manada de Lobos entre e inmediatamente mate a todas tus ovejas

Este es un Juego realizado para la Materia de Optimización de Videojuegos

# CONTROLES

Los controles constan de Teclado y Gamepad

| ACCION                                             | TECLADO    | GAMEPAD                           |
|:---------------------------------------------------|:----------:|----------------------------------:| 
| **Girar Camara**                                   | Mouse      | GamePad Right Thumbstick          |
| **Cambio de Camara (1era Persona / 3era Persona)** | P          | GamePad Left Shoulder             |
| **Movimiento**                                     | WASD       | GamePad Left Thumbstick           |
| **Saltar**                                         | Espacio    | GamePad Face Button Bottom        |
| **Correr**                                         | Left Shift | GamePad Right Trigger             |
| **Abrir inventario**                               | M          | Gamepad D-pad Up                  |
| **Hablar**                                         | L          | GamePad Right Shoulder            |
| **Pausar Juego / Menu de Pausa**                   | O          | GamePad Special Right             |
| **Disparar (No implementada)**                     | U          | GamePad Left Trigger              |
