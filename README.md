# NightFallRanch_Game

# Qué es Nightfall Ranch

Nightfall Ranch es un videojuego shooter donde el jugador tendrá la tarea de defender su rancho
El gameplay se trata de balancear tu atención entre 2 tareas:
    Evitar que los Lobos (que constantemente entrarán a tu Rancho) logren matar a tus ovejas
    Mantener tus Generadores funcionando al cargarlos para evitar que su bateria llegue a 0 y tu Cerca Electrica falle, haciendo que toda la manada de Lobos entre e inmediatamente mate a todas tus ovejas

Los controles constan de Teclado y Gamepad
